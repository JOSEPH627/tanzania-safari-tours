\# Tanzania Safari \& Tours



A WordPress-based tourism and safari website designed to showcase Tanzania's destinations, safari experiences, tours, activities, and travel information.



The project is being developed as a practical Tourism \& Safari Management System for \*\*Tanzania Safari \& Tours\*\*, with the goal of supporting both public visitors and future business management operations.



\## 🌍 Project Overview



\*\*Tanzania Safari \& Tours\*\* is a tourism platform focused on promoting Tanzania as a travel destination.



The website is designed to provide visitors with information about:



\* Safari destinations

\* Wildlife and nature experiences

\* Tour packages

\* Activities

\* Travel information

\* Destinations and attractions

\* Customer inquiries and bookings

\* Travel guides and blog content



The project will gradually be expanded from the public-facing website into a complete tourism and safari management system.

\## 💻 Local Development



To run the project locally:



\### 1. Install XAMPP



Install XAMPP with:



\* Apache

\* MySQL/MariaDB

\* PHP



\### 2. Clone the repository



```bash

git clone https://github.com/JOSEPH627/tanzania-safari-tours.git

```



\### 3. Move the project



Place the project inside the XAMPP `htdocs` directory:



```text

C:\\xampp\\htdocs\\

```



\### 4. Create the database



Create a MariaDB/MySQL database named:



```text

tourism\_db

```



\### 5. Configure WordPress



Create/configure the local `wp-config.php` file with the appropriate database credentials.



\*\*Do not commit database passwords or other sensitive credentials to GitHub.\*\*



\### 6. Start XAMPP



Start:



\* Apache

\* MySQL



Then open:



```text

http://localhost/wordpress

```



\## 🔐 Security



Sensitive configuration files are excluded from Git using `.gitignore`.



Examples include:



```text

wp-config.php

.env

```



Database credentials and private information should never be committed to the repository.
